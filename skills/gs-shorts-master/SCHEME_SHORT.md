# Канон шортса «Схема на фразу» (линия Э, с 12.10.2026)

Слово Гора 12.10.2026: «скрипт шортса в канон». Источник: реверс рилса Александра Захарова (TG, пост 251; 25 444 просмотра, средний просмотр 16 с из 51, больше тысячи сохранений). Полный разбор, кадры, спектр и расшифровка: `C:/CLAUD/_research/reel-reverse-2026-10-12/REVERSE.md`. Машинный шаблон сценария: `scheme_short_template.json` рядом.

Суть формата: каждая фраза голоса получает свою мини-схему, элементы появляются на слово, которое их называет, титры собираются по слову, звук щёлкает на каждое событие. Плотность моушна держит внимание вместо смены кадров.

Темп: 2,9-3,2 слова/с ровно во всех тактах (у нас xAI на скорости 1,25 даёт близко). Пауз длиннее 0,25 с нет: тишина и оговорки вырезаны встык. Длина 45-55 с, 140-160 слов (это выше нашего потолка 95-140 из п.4 мастер-скила: для линии Э действует этот канон).

Под наш канал такты ложатся на темы мастерской так: хук «Как получить +N % FPS без новой видеокарты?» -> повод (вышел драйвер, нашли настройку, замерили на стенде) -> механизм одной фразой -> применение на зрителя -> 2-3 цифры замера из facts -> «Как это работает?» схемой -> «Как включить у себя?» по шагам (BIOS, драйвер, утилита) -> призыв «пишите «СЛОВО», пришлём профиль/гайд» (лид-магнит в воронку TG и MAX).

## 2. Монтажные законы формата
- **Титры по слову.** Две строки по центру примерно на 60 % высоты: первая обычная, вторая жирная, ключевое слово цветом. Слова появляются ровно по таймкодам речи (`C:/CLAUD/tools/asr_client.py ФАЙЛ --out x.json`, слова с началом и концом). Строка сменяется по фразе, не по счётчику символов.
- **Схема на фразу.** Каждая смысловая фраза = свой мини-кадр: карточка, чек-лист, развилка, петля проверки, табло цифр, полоски нагрузки, гонка, штамп. Элемент выходит на слово, которое его называет («тест упал» -> красный бейдж). Новое событие каждые 0,3-0,5 с.
- **Мало склеек, один холст.** У эталона 6 жёстких склеек на 51 с, остальное непрерывный моушн: элементы переезжают, схема перестраивается. Плывущий слайд запрещён по-прежнему: движение = событие под слово.
- **Главы крупным заголовком** по центру на пустом поле («Как работает эта связка?», «Как настроить у себя?»), 1-1,5 с.
- **Сквозной персонаж.** Маскот носит сюжет между схемами (у эталона пиксельные зверьки). У нас свой персонаж GS, выбор = вердикт Гора; без людей и аниме-фигур по законам кадра, значит маскот предметный (пиксельная плата, вентилятор с глазами-диодами и т.п.).
- **Звук на событие.** Щелчок или «пинг» (тон около 2,7 кГц) на каждое появление, удар саба на смене главы, подложка с басом, громкость по главам. Голос сверху, подложка на -18...-22 дБ под ним.
- **Голова по краям.** У эталона лицо на хуке (сплит: карточка сверху, лицо снизу) и на призыве. У нас лицо только живое, если Гор снимется сам; иначе хук и призыв карточкой с голосом.
- **Палитра и вид.** Белая бумага с еле видной сеткой точек, белые скруглённые карточки с мягкой тенью, зелёная галочка и красный крестик бейджами. В наших токенах `tools/gs_style.py`: серый, голубой, белый, оранжевый (фирменная палитра 11.10); инфографика «Лаборатория» в лонгах не меняется.
- **Кадр.** 1080x1920 (у эталона 1440x2560), 60 к/с для моушна.

## 3. Наши законы поверх формата (они главнее)
| у эталона | у нас |
|---|---|
| цифры бегут счётчиком (210 289 -> 1 000 000) | цифра финальная с первого кадра, подсветка на слове (`--motion law`); счёт только в промо |
| голос автора | живой голос Гора или xAI (п.4 мастер-скила), двойника нет |
| лицо автора | только живая съёмка Гора; генерированных лиц нет |
| макеты интерфейса Codex | доля товара ≥ 20 %: фото и скрины железа, BIOS, утилит (`toolkit_gate.py`, `visual_share`) |
| весь моушн плоский | моногатари 30 % ± 10 %: схемы anatomy, рилы Д карточкой, «Шин» на механизм |
| пиксельные маскоты | генератив ≤ 20 %: спрайт маскота рисуется один раз и дальше двигается кодом |
| факты «создатели заявляют» | гейт фактов обязателен, цифры только из facts |

## 5. Самопроверка формата (сверх общей)
- Пауза между словами не больше 0,25 с (замер по `asr.json`).
- На каждую фразу есть своё событие на экране, без «пустых» 1,5 с.
- Каждое слово титра выходит не раньше своего начала в речи и не позже чем через 0,1 с.
- Звук: событие = щелчок, глава = удар; голос разборчив поверх подложки (ASR распознаёт ≥ 97 % слов сценария).
- Призыв содержит одно слово-код и одно действие.
