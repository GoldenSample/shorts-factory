# Чужие футажи: законно и без штрафов

Собран 01.10.2026 по просьбе Гора («вшей в ВПС футажи из чужих роликов, рисерч как законно, чтоб не проштрафиться»). Подробный разбор с источниками: `shortsmaker/docs/research/footage-legal.md`.

## Право в пяти строках

1. **Цитата (ГК РФ ст. 1274)**: чужое видео можно без согласия и без оплаты в информационных, критических, полемических целях **в объёме, оправданном целью**, с **обязательным указанием автора и источника**. Пленум ВС № 10 (2019): цитата не должна подменять оригинал.
2. **Логотипы и водяные знаки автора не вырезать** — удаление информации об авторском праве само по себе нарушение (ст. 1300) и повышает компенсацию.
3. **Цена ошибки**: компенсация по ст. 1301 от 10 000 ₽, верх с 04.01.2026 — 10 млн ₽ (до этого 5 млн; сверить с текстом закона); КоАП 7.12 до 40 000 ₽ юрлицу при цели дохода; YouTube — Content ID, страйк, три страйка = канал удалён; монетизация повторного контента — только при своём разборе.
4. **Чище цитаты**: свои съёмки и генерация; CC BY на YouTube (поле `license` у yt-dlp); пресс-материалы производителей по их условиям; стоки с коммерческой лицензией.
5. **Звук чужого ролика не берём никогда**: музыка — отдельный объект права и главный источник блокировок.

## Пороги (держит код, не человек)

| правило | порог | где держится |
|---|---|---|
| источник | только белый список с классом лицензии | `footage_intake.py` |
| длина фрагмента citation | ≤ 4 с (cc-by/press 6 с, stock 8 с) | `footage_intake.py` |
| звук | вырезан | `footage_intake.py` |
| кадр | целиком на размытой подложке, без кропа логотипов | `footage_intake.vertical()` |
| подпись в кадре | «Видео: <автор>» вшита (полоса 1366 px, под караоке) | `footage_intake.vertical()` |
| под какую реплику | только где есть конкретное слово из названия ролика (бренд без модели не считается) | `build_short.ext_pick()` |
| повтор | каждый фрагмент один раз на ролик | `build_short` |
| доля чужого | ≤ 25 % хронометража (`SHORTSMAKER_EXT_SHARE`) | `build_short` |
| автор и ссылка | `script["ext_credits"]` → подпись ТГ, shorts_log, пакет ВК | `build_short`, `vk_poster` |
| сайт gspc-lab.pro | чужих кадров нет вообще | правило владельца |

## Конвейеры

- **Ночной build_short и дайджест-шортс** (дайджест собирается через build_short): фрагмент первым кадром сцены, банк добирает остаток; покадровый гейт не спрашивает тему в окнах чужих фрагментов (`frame_gate.py --trust a-b,...`), остальное проверяет; при пересборке сцены её фрагмент и автор снимаются.
- **Игровые кадры** (`game_footage.py` → `build_short.game_clips_for`): регистрируются тем же форматом через `footage_intake.register()` с подписью канала (часто IGN, а не издатель — подписываем того, кто выложил).
- **Ручные сборки** (шаблон `docs/scripts/lok-pbo/build.py`): в plan.json кадр `{"ext": "слова из названия ролика"}`; авторы уходят в подпись ТГ и `ext_credits.json`.
- **ВК** (`vk_poster.py`): строка «В ролике фрагменты: <авторы>» без ссылки и без названия площадки (гейт ВК режет ссылки и упоминания других площадок).
- **YouTube (ручная заливка)**: в описание последним блоком строки из `ext_credits` — «Видео: <автор> — <ссылка на ролик>».

## Команды (VPS, /opt/shorts)

```bash
python3 footage_intake.py list                                     # источники и сколько фрагментов
python3 footage_intake.py add https://www.youtube.com/@NVIDIAGeForce --class citation --credit "NVIDIA GeForce" --name nvidia-geforce
python3 footage_intake.py run --per 1 --n 6 --keep 6               # то же делает крон раз в 6 часов
python3 footage_intake.py verticals --force                       # перерисовать подписи (если сырые целы)
SHORTSMAKER_NOEXT=1 python3 build_short.py ...                    # собрать без чужих кадров
```
Файлы: `/opt/shorts/footage_sources.json`, `/opt/shorts/ext/<источник>/<id ролика>/clip_NNN_v.mp4 + .json`, архив `/opt/shorts/ext/archive.txt`, лог `/opt/shorts/footage.log`, крон `/etc/cron.d/footage-intake`.

## Чек-лист перед публикацией наружу

1. В ролике чужой фрагмент — есть ли вшитая подпись автора на всё время фрагмента.
2. Наш голос в этот момент разбирает то, что видно (цитата иллюстрирует, а не заменяет).
3. Чужого ≤ 25 % и каждый кусок ≤ 4 с.
4. Звук фрагмента не слышен (только наш голос и своя музыка).
5. В описании YouTube и в посте ВК — авторы (в YouTube со ссылкой).
6. Источник в белом списке; новый источник — только с согласия Гора.
