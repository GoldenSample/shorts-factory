# LongCat-Avatar: ведущий под наш голос

Модель: `LongCat-Video-Avatar-1.5` (Meituan, MIT). Дорожка речи ведёт видео от опорного кадра.
Стоит дома на 5090 (10.77.0.2 через хаб <VPS_IP>), гоняется с VPS клиентом
`shortsmaker/vps/home_gen.py longcat`. Полные исследования от 22.09.2026 — в
`shortsmaker/docs/research/longcat/{prompting,finetune,production}.md`, здесь выжимка.

## Быстрый старт

```bash
# на VPS, из /opt/shorts
python3 home_gen.py flux "<описание ведущего>" lab/kadr.png --width 480 --height 832
python3 home_gen.py longcat "<промпт речи>" out.mp4 --audio voice.wav --image lab/kadr.png --frames 93
```

- Кадр вертикальный 480×832, кратный 16, лицо не у края (голова двигается — нужен запас).
- `--frames` = ceil(секунды × 25). 93 кадра = 3,72 с = один сегмент (длина обучающего клипа).
- Дорожка — сухой голос без музыки и реверба; громкость не трогать, `normalize_loudness` сам приведёт к −23 LUFS.
- Первый кадр сохраняй как эталон: один и тот же ведущий во всех роликах — это один и тот же файл.

## Схема, которая работает (проверено 22.09.2026)

```
LoadImage → WanVideoEncode ─┬→ prev_latents ┐
                            └→ ref_latent   ├→ WanVideoLongCatAvatarExtendEmbeds ─┐
LoadAudio → LongCatAvatarWhisperEmbeds ────→ audio_embeds ┘                        │
CLIPLoader(umt5 fp8) → CLIPTextEncode ×2 → WanVideoTextEmbedBridge ───────────────┤
WanVideoLoraSelect(dmd, 0.9, merge off) → WanVideoModelLoader(GGUF Q8, bf16, sdpa) ┤
WanVideoSchedulerv2(longcat_distill_euler, 12, shift 12) → WanVideoSamplerv2(cfg 1) ┘
→ WanVideoDecode(Wan2_1_VAE) → CreateVideo(25 fps, audio из Whisper-ноды) → SaveVideo
```

Три грабли, на которых уже стояли:
1. `WanVideoEmptyEmbeds` модель не принимает (`tensor a (4096) vs b (128)`). Только `ExtendEmbeds`; для варианта без кадра — та же нода с `overlap 0`.
2. `WanVideoTextEncodeCached` не берёт наш `umt5_xxl_fp8_e4m3fn_scaled` — он рассчитан на bf16-энкодер. Обход: нативные CLIPLoader + CLIPTextEncode + `WanVideoTextEmbedBridge`. Альтернатива — докачать `umt5-xxl-enc-bf16` (11 ГБ).
3. GGUF не даёт вплавить лору: `merge_loras: false`.

## Параметры и их цена

| Параметр | Ставим | Почему |
|---|---|---|
| `fps` | **25** везде: Whisper-нода, CreateVideo, экспорт | модель 1.5 обучена на 25 fps; 16 — это ветка 1.0 (в примере kijai 16 остался от неё) |
| `audio_cfg_scale` | **1** черновик, 3–4 только финал при вялом рте | значение > 1 включает второй проход модели на каждом шаге = ×2 времени. Наведение 4 уже вшито в distill-лору |
| `audio_scale` | 1.0 → 1.2–1.5 если рот не закрывается | бесплатный рычаг, без второго прохода |
| `num_frames` в Whisper-ноде | **полная длина ролика** | она РЕЖЕТ аудио; в ExtendEmbeds — длина окна (93). Оставишь 93 в обеих на длинном ролике — хвост жуёт начало фразы |
| `overlap` | 1 первый сегмент, **13** продолжение, 0 без кадра | эталон kijai; 13 = официальный num_cond_frames |
| `ref_frame_index` / `ref_mask_frame_range` | 10 / 3 | работают только при подключённом `ref_latent`. 0–24 = якорь личности, 30 = меньше повторов жестов |
| `steps` / `shift` / `cfg` | 12 / 12 / 1 | эталон kijai; официальная дистилляция — 8 NFE, замерить 8 |
| лора dmd | 0.9, merge off | эталон kijai; официально 1.0 |
| `attention_mode` | sdpa, или sageattn ≥ 2.2 | **sage 1.0.6 молча выбрасывает опорный кадр** (issue #1780) |
| `base_precision` | только bf16 | иначе не работает |
| разрешение | 480×832 (480p) или 720p | ничего другого модель не знает; 1080×1920 делаем апскейлом |

Замеры 22.09 (93 кадра 480×832, sdpa, offload_device): audio_cfg 4 — **402 с**, рот открывается, язык виден; audio_cfg 1 — **208 с**, рот почти не открывается на русском голосе. Пик ОЗУ дома в прогоне 25,3 ГБ (старт 7,6), видеопамяти 22,3 ГБ. Не замерено: sageattn ≥ 2.2, load_device main_device, steps 8, audio_scale 1.5 при cfg 1.

## Промпт

Каркас 35–70 слов, одно-три предложения, по-английски:
**КТО + внешность → глагол речи (`is speaking`) → одежда с деталью → поза → сцена и свет одной фразой → хвост про атмосферу.**
Для двух персонажей первым словом `Static camera,`.

Кадрирование задаётся не камерой, а перечислением видимого (совет kijai): нужен поясной план — назови воротник и руки на столе; ростовой — обувь. Негатив наезд камеры не лечит.

Заготовки под мастерскую и разбор — `reference/prompting.md`.

## Длинная речь: сегменты

Один сегмент — 93 кадра. Непрерывный план дольше 20–30 с сыпется по личности и цвету (техотчёт признаёт). Правила:
- речь резать на смысловые куски 3–8 с, между ними — перебивки железа;
- аватар в кадре не дольше 8 с подряд, кадр 0 ролика — реальный предмет с цифрой, не аватар;
- продолжение внутри куска — второй `ExtendEmbeds` с `overlap 13`, `frames_processed 93`, плюс `prev_images` + `vae` (путь 1.5), иначе шов виден. В `home_gen.py` этого пока нет — дособрать перед первым длинным роликом.

## До 1080×1920 и 30/60 к/с

Порядок предпочтения, по цене установки:
1. **Нейрорендер на :7860** (уже стоит): вкладка апскейла (`VSR quality` 1–4, множитель или точные размеры) и вкладка интерполяции (`Output FPS` до 480). Ноль установок, NVENC на выходе. Проверять зубы и язык покадрово после.
2. FlashVSR — уже внутри WanVideoWrapper, докачать три файла из `Kijai/WanVideo_comfy/FlashVSR`; сам автор пишет «не совпадает с оригиналом».
3. SeedVR2 — отдельный нод, профиль «короткий ИИ-клип из 480p», лучший по отзывам на нашем типе входа.
Интерполяция обычно не нужна: 25 fps нативные. Если надо 50 — GIMM-VFI, RIFE даёт гостинг на губах.

## Файнтюн: НЕ тюнить

Тренера под Avatar-ветку нет (единственный форк учит базовую видео-модель без аудио), персонажных лор нет ни у кого, конвертера ключей под обёртку нет, база нужна bf16 вместо нашего GGUF. Вместо этого — бесплатные ручки: один эталонный кадр в `ref_latent`, постоянный текстовый блок внешности, фиксированный seed, fps 25 по всей цепочке, сшивка через `prev_images`. Узнаваемость канала и так держится голосом. Подробно — `reference/finetune.md`.

## Приёмка и публикация

Полный чек-лист — `checklist.md`. Жёсткие пункты:
- в логе ComfyUI нет `Not enough audio features, padded` (иначе хвост артикулирует начало);
- рот закрывается на «м», «п», «б»; задержка губ ≤ 2 кадров;
- первый и последний кадр сцены — один цвет кожи и фона;
- YouTube: галка «изменённый или синтетический контент»; в описании строка «Ведущий сгенерирован ИИ»;
- лицо — либо сотрудник с письменным согласием, либо полностью синтетическое; цены не называем; аватар не представляется живым мастером.
