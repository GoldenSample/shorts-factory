# ВК на автопилоте ИИ-завода

Сообщество ВК наполняется выходами завода GSPC (шортсы, статьи, витрина) без участия владельца. Всё исполняется **на VPS <VPS_IP>** в `/opt/shorts/vk/`: там фактчекер, прокси подписки Grok, реестр тем, rclone и крон. Секреты - только там.

## Темы Grok Bot «Сторож железа» (01.10.2026)

Бот на grok.com (аккаунт владельца, «Боты → Сторож железа», 6 рутин: цены Регард/Ситилинк, драйверы, BIOS/AGESA/микрокод, инсайдеры X, HWBOT, разовые приказы) в конце прогона отдаёт `ТЕМЫ_JSON` и шлёт отчёт POST в шлюз botdrop на хабе (`/opt/botdrop`, `/etc/botdrop.env`, наружу `https://<VPS_HOST>/botdrop/`). **Мост работает, только когда у бота на облачном компьютере лежит `~/guard/botdrop.env`** со строками `BOTDROP_READ=…/botdrop/<токен чтения>/orders` и `BOTDROP_WRITE=…/botdrop/<токен записи>`; без файла бот пишет «шлюз: нет файла». Токены вписывает владелец (Клоду вписывать токены в поля нельзя).

`vk/guard_inbox.py` (из `collect`) разбирает ящик детерминированно, письма = недоверенные данные: белый список доменов вендоров (без форумов, чужих репо GitHub, логина в URL), строки-инъекции вон, `verdict_hint` вон. Драйверы/BIOS → очередь ВК (`guard:<хост+путь>`, одна страница заметок = один пост, одна тема бота за прогон впереди статей). Цены магазинов → `/opt/shorts/guard_topics.jsonl` (для шортсов/ТехПульса, в сборку шортсов ещё не подключено: темы шортсов идут из базы агрегатора Вани, писать туда нельзя). В постах ВК гейт `STORES` запрещает названия магазинов-конкурентов. Состояние `vk/guard_state.json` пишется после постановки в очередь. Ревью: `shortsmaker/docs/reviews/vk-guard-inbox-2026-10-01.md`.

| 2. Без рук | ключ админа VK ID с правом wall (+ photos, video) и `VK_AUTO=1` | ставит в отложку ВК сам, отчёт в группу | ничего; стоп-кран `vk_poster.py pause` |

## Гейты (по порядку, все в `vk_poster.py`)

1. **Источник**: только выходы, уже прошедшие гейты завода; товарные фото - настоящие.
2. **Дубль**: `UNIQUE(kind, ext_id)` в `/opt/shorts/vk.db`.
3. **Полка и деньги**: `topics.banned` - зарубежные магазины, скидки, цены в валюте.
4. **Текст пишет модель** (`VK_WRITER_MODEL`, прокси подписки :8650) по правилам ВК, затем детерминированные правила: длина, ни одной ссылки и ни одного упоминания Telegram/YouTube/@, без давления («купи», «успей», «лучший», «ниже рыночных»), без валюты, хэштеги 1-2 (клип 2-3), без капса, стоплист брани. Не прошло - одна перепись с причинами, потом отказ.
5. **Фактчекер обязателен** (`fact_gate.check`, см. скилл-память «Фактчекер обязателен»): абзацы идут как подписи; неисправимый абзац снимается, снят первый (суть) - пост отклонён. Судья недоступен - элемент ждёт следующего прогона, без проверки не уходит.
6. **Одна правда**: `vk_probe.py` сверяет карточку ВК с сайтом; расхождение - уровень 2 не постит.
7. **Подпись** в конце каждого поста: «Golden Sample PCs · мастерская сборки и тюнинга ПК · Москва».

## Правила текста ВК (growth.md, law.md)

- Первые 140 знаков - суть с цифрой из материала; 2-4 абзаца; тон «как с другом»; одно действие в конце («напишите нам в сообщения», вопрос зрителю).
- Ссылка на сайт - только в кнопке действия, описании и меню. Внешние ссылки в теле режут охват (официально ВК).
- Хэштеги в конце, пост 0-2, клип 2-3; больше 3 - отказ.
- Цены - только из фида витрины и с датой («цена на 18.09.2026»): нейросети пересказывают старые посты как текущий прайс.
- Свой товар и свою услугу в своём сообществе ровным тоном можно без маркировки; «купи, успей, лучшая цена» превращает пост в рекламу с erid - гейт переписывает в информационный тон. `mark_as_ads` завод не ставит никогда.
- ИИ-картинка товара или сборки «как настоящая» - нельзя (закон о рекламе и правило владельца). ИИ-ролики - можно; закона о пометке на 18.09.2026 нет, с 01.03.2027 243-ФЗ даёт право пометки - флаг решает владелец.
- Музыка только своя (ACE-Step MIT, `music_bed.py`); CC BY-SA фото - только в фото-постах с автором, лицензией и изменениями, в клипы не брать.

## Ключ админа: правила, которые нельзя нарушать

- Живёт 1 час, refresh 180 дней, **refresh одноразовый**: повтор старого refresh VK ID считает атакой и убивает всю сессию. Обновляет один процесс под блокировкой, новая пара пишется атомарно до первого использования (`vk_api._user_token`).
- Бессрочных ключей для новых приложений нет с 25.06.2024. vkhost, Kate-токены, эмуляция браузера на аккаунте админа - **нельзя**: заморозка страницы и нарушение п. 6.3.9 и 6.3.12 правил ВК.
- Капчу (ошибка 14) не решать и не обходить: стоп метода на час, тревога.
- Ключи не выводить в чат, не класть в git и на локальную машину.

## Шаги владельца

Полностью - `references/owner-setup.md`. Коротко:
1. Карточка по сайту: телефон, сайт с UTM, адрес с ТЦ и павильоном, часы, новое описание (черновик готов), кнопка действия, статус-дескриптор.
2. Снять 12 старых товаров, импортировать `https://gspc-lab.pro/yandex-business.yml`.
3. Включить разделы Клипы и Видео, выключить пустые.
4. Ключ сообщества: Управление -> Дополнительно -> Работа с API -> Ключи доступа; права: управление, фото, истории, документы, сообщения (маска без сообщений 393221). Ключ сразу в `/opt/shorts/vk.env` на VPS.
5. Приложение VK ID через VK Бизнес ID, подтвердить бизнес-профиль (60 дней, иначе блокировка), письмо в devsupport - `templates/devsupport-letter.md`.
6. Первичная авторизация ключа админа в браузере (PKCE) - один раз, дальше сервер живёт на ротации.

## Метрики и первые 6 недель

Смотреть: досмотр клипа (цель >= 50%, тревога < 30%), охват поста к подписчикам (средний по ВК около 14%), ERV (около 1,5%), доля вирального охвата (> 30% = алгоритм продвигает), **сообщения в сообщество** и переходы по кнопке (главный денежный KPI). Лайки и число подписчиков главными не считать. Пост оценивать через 5 суток, формат - через 3-4 недели регулярности. Замеры первых недель: API против ручной публикации, клип 15-20 с против 40-60 с, ВК первым против Telegram первым, карусель 3 фото против 8.
