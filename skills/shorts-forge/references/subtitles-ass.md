# СУБТИТРЫ ASS: замеренная техника

Прогнано на **ffmpeg 8.1.2 (gyan full), libass 0.17.5, провайдер шрифтов directwrite.**

## ⚑ PRIMARY И SECONDARY РАБОТАЮТ НАОБОРОТ ИНТУИЦИИ

| Цвет стиля | Когда виден |
|---|---|
| `SecondaryColour` | слово **ещё не прозвучало** |
| `PrimaryColour` | слово **уже прошло** |

Подсветка «бегущего» слова делается **не Primary**, а тем, что стоит в Secondary до него.

| Тег | Поведение | Годность |
|---|---|---|
| `\k<сс>` | мгновенный скачок Secondary→Primary | да, классика |
| `\kf<сс>` (=`\K`) | плавная заливка слева направо | да, «жидкое» караоке |
| `\ko<сс>` | **непройденная часть теряет обводку целиком** | ⛔ убивает читаемость |

Длительность в **сотых долях секунды**, отсчёт от `Start`, сумма всех `\k` = длине события.

## ОГРАНИЧЕНИЕ `\k`, ИЗ-ЗА КОТОРОГО TikTok-СТИЛЬ ДЕЛАЮТ ИНАЧЕ

`\k` умеет менять **только цвет** — ни размер, ни позицию, ни блюр он не анимирует.
Поэтому «поп» активного слова (крупнее + другой цвет) строится **отдельным событием на каждое
состояние**: группа из 2-3 слов показывается N раз подряд, каждый раз с активным словом в оверрайдах.
```
Dialogue: 1,0:00:00.00,0:00:00.60,Pop,,0,0,0,,{\an5\pos(540,1330)}{\c&H27E3FC&\fscx112\fscy112}СТАНОК{\r}\h ПРОДАЁТ
Dialogue: 1,0:00:00.60,0:00:01.80,Pop,,0,0,0,,{\an5\pos(540,1330)}СТАНОК\h {\c&H27E3FC&\fscx112\fscy112}ПРОДАЁТ
```
`{\r}` сбрасывает к стилю события. Побочка `\fscx`: строка меняет ширину и при `\an5`
перецентровывается — виден горизонтальный джиттер. Либо терпеть (это и есть «живость»),
либо не масштабировать, либо каждому слову свой `\pos`.

## ⚑ ГРАБЛЯ: ТОЛСТАЯ ОБВОДКА СЪЕДАЕТ ПРОБЕЛ

При `Fontsize=104` и `Outline=7` обводки соседних слов смыкаются — «СТАНОК ПРОДАЁТ» читается
как «СТАНОКПРОДАЁТ». Пробел на месте, его закрашивает контур (7px с каждой стороны из ~30px пробела).
**Лечение: `\h`** — неразрывный пробел, который не схлопывается: `СЛОВО\h СЛОВО`.
⛔ Увеличивать `Spacing` в стиле нельзя — он раздувает межбуквенный интервал внутри слов.

## ЧИТАЕМОСТЬ НА ЛЮБОМ ФОНЕ: ТРИ СЛОЯ

Обводки мало: на белом чёрный контур ещё держит, на пёстром нет.
1. **Гало** (отдельное событие `Layer 0`): копия текста, заливка невидима (`\1a&HFF&`),
   огромная полупрозрачная обводка с блюром — мягкая тёмная подложка по форме текста.
2. **Обводка**: `BorderStyle=1`, `Outline: 6`, чёрная.
3. **Тень**: `Shadow: 4`, `BackColour=&HA0000000`.

Альтернатива `BorderStyle=3` — сплошная плашка, максимум читаемости, минимум вкуса.

**Цвет:** в стилях `&HAABBGGRR` (8 знаков, BGR наоборот), в тегах `&HBBGGRR&` (6) + альфа
отдельно `\1a&HAA&`. **Альфа: `00` = непрозрачно, `FF` = прозрачно.**

## ГОТОВЫЙ ЗАГОЛОВОК 1080x1920

```ass
[Script Info]
ScriptType: v4.00+
WrapStyle: 2
ScaledBorderAndShadow: yes
YCbCr Matrix: TV.709
PlayResX: 1080
PlayResY: 1920

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Pop,Arial Black,104,&H00FFFFFF,&H00202020,&H00000000,&HA0000000,-1,0,0,0,100,100,2,0,1,6,4,2,80,80,430,204
Style: Halo,Arial Black,104,&H00000000,&H00000000,&H00000000,&H00000000,-1,0,0,0,100,100,2,0,1,22,0,2,80,80,430,204
Style: Kara,Arial Black,104,&H00FFFFFF,&H0020C0FF,&H00000000,&HA0000000,-1,0,0,0,100,100,2,0,1,6,4,2,80,80,430,204

[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
Dialogue: 0,0:00:00.00,0:00:01.80,Halo,,0,0,0,,{\an5\pos(540,1330)\blur16\1a&HFF&\3a&H40&}СТАНОК\h ПРОДАЁТ
Dialogue: 1,0:00:00.00,0:00:00.60,Pop,,0,0,0,,{\an5\pos(540,1330)}{\c&H27E3FC&}СТАНОК{\r}\h ПРОДАЁТ
Dialogue: 0,0:00:01.80,0:00:03.60,Kara,,0,0,0,,{\an5\pos(540,1330)}{\kf60}СЕБЯ\h {\kf60}САМ\h {\kf60}ТЕПЕРЬ
```

Обязательные поля:
- ⚠ **`PlayResX/Y` = размеру видео.** Классическая причина «шрифт вдруг стал крошечным»:
  SRT, сконвертированный ffmpeg'ом, получает `PlayResY: 288`, и `FontSize=13` там значит 13/288 высоты.
- `ScaledBorderAndShadow: yes` — обводка и тень масштабируются с текстом.
- `YCbCr Matrix: TV.709` — корректный перевод RGB стиля в колорспейс видео.
- `WrapStyle: 2` — запрет автопереноса (для 1-3 слов на событие то, что нужно).
- `Bold=-1` — да, минус единица, это «true» в ASS.
- Строка `Format:` в стилях — ровно 23 поля, в событиях 10. Порядок нарушать нельзя, libass читает по позиции.
- `\pos` полностью отменяет `MarginL/R/V`. При `Alignment=2` `MarginV` меряется **от низа кадра**.

## ЭКРАНИРОВАНИЕ ПУТЕЙ (замерено, что падает)

```bash
# ✅ РАБОТАЕТ
ffmpeg -i in.mp4 -vf "subtitles='C\:/CLAUD/work/sub.ass'" out.mp4
ffmpeg -i in.mp4 -vf "subtitles=C\\:/CLAUD/work/sub.ass" out.mp4
# ❌ ПАДАЕТ — кавычки НЕ защищают двоеточие
-vf "subtitles=filename='C:/CLAUD/work/sub.ass'"   # No option name near '/CLAUD/...'
# ❌ ПАДАЕТ — бэкслеши съедаются как escape
-vf "subtitles='C\:\CLAUD\work\sub.ass'"           # Unable to open C:CLAUDworksub.ass
```
**Правило: `\` → `/`, потом `:` → `\:`, потом всё в одинарные кавычки.**
Пробелы, кириллица и скобки внутри кавычек проходят как есть.
```python
def esc_ass(p): return str(p).replace("\\", "/").replace(":", r"\:")
```

`force_style` (запятые защищены одинарными кавычками) чинит шрифт и размер, **но не даёт
многослойности**: замер показал подъём сигнала титра с 1.3 до 18.8, тогда как полноценный ASS
с гало-слоем даёт 40.1. Для шортсов писать полноценный ASS.

Мастер кодировать **щедро** — `crf 16-18`, `preset slow`: площадка всё равно перекодирует,
отдавать ей уже подпорченный титр = терять дважды.

## ЧТО ДЕГРАДИРУЕТ ПОСЛЕ ПЛАТФОРМЫ (замер)

Две метрики без зависимостей, только ffmpeg. **SIGNAL** — модуль разности «с титром / без титра»
в полосе титра (оба через одинаковый пайплайн). **EDGE** — лапласиан по полосе титра.

| стиль / стадия | SIGNAL | EDGE | потеря краёв |
|---|---|---|---|
| **good** / мастер | 39.88 | 2.815 | — |
| good / 1080 @1.2M | 39.89 | 2.821 | 0% |
| good / 720 @700k | 39.89 | **2.193** | **−22%** |
| **bad** / мастер | 1.27 | 1.325 | — |
| bad / 720 @700k | 1.35 | **0.718** | **−46%** |

`good` = Arial Black 104, белый, Outline 6 + гало. `bad` = Segoe UI Light 52, серый на сером, Outline 1.

Читается так: **SIGNAL — ворота стиля** (разница в 30 раз видна уже на мастере, до платформы).
**EDGE — ворота выживания:** перекодирование в том же разрешении почти не вредит, а даунскейл
1080→720 съедает у толстого титра 22%, у тонкого 46%. Тонкий шрифт теряет вдвое быстрее —
штрих в 1-2px после ресайза перестаёт существовать.

**Пороги для гейта:** `SIGNAL ≥ 25` и `EDGE(720)/EDGE(мастер) ≥ 0.75`.

Что именно ломается: тонкие штрихи · низкий контраст (кодек считает серое-на-сером дешёвым и
выкидывает первым) · антиалиасинг и блюр (DCT квантует градиент в ступеньки, «звон») ·
**хроматическая субдискретизация 4:2:0** — насыщенный цветной текст без светлотного контраста
расплывается, поэтому **подсветка активного слова должна отличаться не только тоном, но и яркостью**
(жёлтый Y≈0.86 против белого Y=1.0 держится, красный на белом нет) · мелкое движение титра
(каждый кадр с новым `\fscx` = новый интра-блок, ест биты у самого текста).

Локальный прогон под платформу: `-b:v 1200k -maxrate 1400k` (1080p) и
`scale=720:1280 -b:v 700k` (худший случай). Проверять глазами на **кропе полосы титра**, не на всём кадре.

## КИРИЛЛИЦА И ТОФУ

⚠ **Типичный отказ — не пустые квадраты, а тихая подмена шрифта и поехавшая вёрстка.**
Замер: `Fontname: Wingdings` дал вингдингсовы значки на латинице, а кириллицу молча подставил
другим шрифтом. Несуществующий шрифт молча ушёл в `Arial-BoldMT`.

**Детектор подмены** (ставится в CI одной строкой):
```bash
ffmpeg -loglevel verbose -i src.mp4 -vf "subtitles='$sub'" -f null - 2>&1 | Select-String 'fontselect'
```
```
fontselect: (Arial Black, 400, 0) -> Arial-Black, 0, Arial-Black      ← ок
fontselect: (NoSuchFontXYZ, 700, 0) -> Arial-BoldMT, 0, Arial-BoldMT  ← ПОДМЕНА
```
Левая и правая часть не совпали — шрифт не тот.

**Гарантированная кириллица:** Arial / Arial Black (`ariblk.ttf`) · Impact (узкий, влезает больше слов) ·
Verdana / Tahoma · Segoe UI Black (только Win8+) · DejaVu Sans Bold (дефолт Linux) ·
Liberation Sans (метрически совместим с Arial).
⛔ **Нет кириллицы:** Wingdings, Webdings, Marlett, Segoe Print/Script, большинство декоративных Google Fonts.

**Детерминированность:** Windows-сборка берёт шрифты через directwrite, Linux через fontconfig —
один ASS даст разный результат на машине и в docker. Лечится `fontsdir` (проверено):
```bash
-vf "subtitles='$(esc $ass)':fontsdir='$(esc $fontdir)'"
```
ASS писать в **UTF-8 без BOM**. `\N` перенос строки, `\h` неразрывный пробел, `ё` писать явно.
Полная герметизация — вшить шрифт в MKV аттачментом.

## ПОБОЧНЫЕ НАХОДКИ

- ⚠ **PowerShell 5.1:** `.ps1` с кириллицей и **без BOM** читается как ANSI и падает на парсинге.
  Скрипты сборки держать в ASCII либо сохранять UTF-8 **с BOM**.
- `ffmpeg -frames:v 1 file.png` ругается «does not contain an image sequence pattern» — нужен
  `-update 1`. Выход при этом 0, легко проглядеть.
- В этой сборке ffmpeg есть **`--enable-whisper`** — пословные тайминги для караоке можно снимать
  локально фильтром, без внешнего сервиса (не гонял, но флаг в конфиге стоит).
- ⚠ `forge.py` `burn_subs` использует SRT + `force_style` с `FontSize=13`. Работает только потому,
  что ffmpeg конвертирует SRT в ASS с `PlayResY: 288`, и 13 разворачивается в ~87px на 1920.
  Хрупко, не даёт ни пословной подсветки, ни гало-слоя.
