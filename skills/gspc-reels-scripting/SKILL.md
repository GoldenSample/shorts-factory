# Сценарий шортса по чужому референсу

По мотивам charlie947/social-media-skills (MIT): reels-scripting. Взято: референс — образец формы, тема — своя; разбор по разделам (полная расшифровка с таймкодами, хук: первые слова, число слов, чем держит; язык: длина фраз, ты/я, связки, смягчители; структура: длительность, блоки с таймингом, момент «было → стало», призыв; один главный приём); зеркалить тип и длину хука, а не слова; один ролик не называть «выбросом» без базы автора; не выдумывать метрики референса; подпись повторяет сценарий; оценка по пяти критериям с доказательствами; при сбое стадии назвать её и взять файл или расшифровку от человека. Изменено: Apify и Gemini 2.5 Flash заменены на yt-dlp на хабе и слух на домашней 5090, анализ делаю сам по счёту скрипта и листам кадров; формат «Из мастерской» вместо 30–45 с LinkedIn-Reels; вердикт мастерской в финале вместо «не говори вывод»; коммент-слово и «пришлю» выброшены (раздачи нет), призыв ставит упаковка; порог 95/100 с тремя кругами заменён жёсткими стопами кодом и фактчекером, балл — строка отчёта.

## Зачем

Чужой ролик, который залетел, показывает работающую форму: какой хук, где развязка, как часто меняется план. Наша задача — перенести форму на свой замер или случай мастерской и не взять у автора ни слова, ни кадра, ни цифры. Канал продаёт доверие к замерам; пересказ чужого ролика его убивает (`gspc-channel-voice`: «нельзя поверхностно повторять»).

Короткая просьба («накидай сценарий по этому рилсу», расшифровка уже в чате) — писать сценарий сразу, без скачивания и счёта (`short-ask-short-answer`).

## Шаг 1. Референс и наша тема

- Ссылка или файл. YouTube Shorts качается на хабе (ЗАМЕРЕНО на `game_footage.py`, нужен `--http-chunk-size 5M`). Клипы ВК и TikTok — yt-dlp без входа, НЕ ПРОВЕРЕНО. Reels Instagram почти всегда требуют входа: не логиниться, попросить Гора сохранить ролик с телефона и прислать файл (дальше `scp` на хаб и тот же скрипт с путём к файлу).
- Тема — своя и с первичкой: пост Research Lab (`Desktop\ТГ\гспс\result.json`), таблица замеров, реплика Гора с датой, слово клиента с согласием. Нет первички — нет ролика: сказать одной строкой, что нужно (замер, фото, слова Гора), и продолжать разбор.
- `slug` — латиница через дефис (`ref-smt-flip`).

## Шаг 2. Скачать и расшифровать (хаб)

```bash
K="-i $HOME/.ssh/gspc_deploy -o BatchMode=yes"          # как в de-leader-3-first5/scripts/verify_clean.sh
ssh -n $K root@<VPS_IP> 'mkdir -p /opt/shorts/reels_ref'
scp $K ~/.claude/skills/gspc-reels-scripting/scripts/ref_pull.sh root@<VPS_IP>:/opt/shorts/reels_ref/ref_pull.sh
ssh -n $K root@<VPS_IP> 'bash /opt/shorts/reels_ref/ref_pull.sh "<url или /путь/файл.mp4>" <slug> ru'   # en для английского, auto — сам
mkdir -p ~/Documents/git/work/reels-ref/<slug>
ssh $K root@<VPS_IP> 'cd /opt/shorts/reels_ref/<slug> && tar cf - meta.json asr.json cuts.txt frame0.jpg sheet_*.jpg' < /dev/null \
  | tar xf - -C ~/Documents/git/work/reels-ref/<slug>        # мелочь одной трубой; ЗАМЕРЕНО 14.10 на /opt/shorts/ref/clean
```

- Скрипт пишет только в `/opt/shorts/reels_ref/<slug>/`: `meta.json` (без комментариев зрителей), `ref.mp4`, `ref16k.flac`, `asr.json`, `cuts.txt`, `frame0.jpg`, `sheet_NN.jpg` (2 кадра/с, 16 с на лист).
- Слух: риг `POST http://10.77.0.2:9099/jobs/asr` файлом → `GET /jobs/<id>` → `GET /files/<id>.json` (faster-whisper large-v3, ~7 с на минуту плюс ~15 с загрузка; голос и слух делят очередь карты). Риг молчит — запасной faster-whisper small на хабе (`/opt/shorts/venv`, CPU), термины он портит: сверять по листам и на слух.
- Ролик на рабочую машину не тянуть: сюда только мелочь (json, листы).
- Сбой стадии — назвать её (yt-dlp, слух, склейки) и предложить файл или расшифровку от Гора. Не изображать разбор без расшифровки.
- НЕ ПРОВЕРЕНО целиком на хабе: при первом прогоне записать в журнал навыка, что встало.

## Шаг 3. Счёт

```bash
py -3.12 ~/.claude/skills/gspc-reels-scripting/scripts/ref_stats.py ~/Documents/git/work/reels-ref/<slug>
```

Пишет `stats.md`: первое слово, хук за 3 с и первая фраза, темп, средняя и самая длинная фраза, ты/вы/я/мы, смягчители, паузы от 0,6 с, склейки и средний план, раскладку фраз по планам. Склейки по `scene > 0,3` мягкие переходы на одном фоне не видят: сверять по листам.

«Выброс» — только с базой автора: `yt-dlp --flat-playlist --print "%(view_count)s" "<канал>/shorts" --playlist-end 30` на хабе, медиана и кратность в разбор (поле просмотров в плоском списке НЕ ПРОВЕРЕНО; нет поля — пишем «референс»).

## Шаг 4. Разбор

Шаблон `references/razbor.md` → `work/reels-ref/<slug>/razbor.md`. Кадр 0 и титры — глазами по `frame0.jpg` и листам (инструмент Read). Итог разбора — один главный приём и строка «берём / не берём». Их слова живут только в разделе «Расшифровка».

## Шаг 5. Наш сценарий

Правила переноса, скелет «Из мастерской» (40–60 с, 8–12 реплик, 650–950 знаков) или «Вспышка» (10–20 с), файлы проекта и пример — `references/scenariy.md`. Голос перед письмом: `Documents\git\work\voice\voice.md` и режим «реплика шортса» навыка `gspc-voice-kit` (`references/modes.md`), если их нет — слог из памяти `gor-voice-slog-2026-10-06`. Коротко:

- тип хука референса, слова свои: голос хука до 30 знаков без цифр и моделей, цифра и модель в титре с кадра 0, первое слово не «я» и не «мы»;
- развязка цифрой там же по времени, где у них «было → стало»; вердикт мастерской одной фразой в финале;
- реплика до 14 слов, полные предложения (три обрубка подряд — брак), польза → факт → название, новое понятие в паре с пояснением;
- дроби словами («меньше половины процента»): xAI читает «0,4» как «ноль запятая четыре»;
- `tg_caption` повторяет сценарий, без цен и @.

Папка `shortsmaker/docs/scripts/<slug>/`: `final.json`, `source.txt` с метками, `theme.json`, `ref.md`.

## Шаг 6. Приёмка до озвучки

1. Заимствования: `ref_stats.py work/reels-ref/<slug> --ours shortsmaker/docs/scripts/<slug>/final.json` — код 3 = цепочка от 5 слов из их речи, переписать.
2. Код сценария на хабе: `check_script.py` из `shortsmaker/docs/scripts/own-9850x3d-air/` вместе с `final.json` и `source.txt` в `/opt/shorts/<slug>/`, запуск HPY (`/usr/local/lib/hermes-agent/venv/bin/python3 check_script.py`). Код 2 = брак: число без источника, деньги, длина, латиница без чтения.
3. Оценка 30/25/20/15/10 с цитатами (`references/scenariy.md` §5) — строкой в отчёт, не поводом для трёх кругов.

## Шаг 7. В конвейер

- Сборка — проектным сборщиком ближайшего пилота (`own-9850x3d-air` для замера, `kingpin-oc` для новости с чужими кадрами): `plan.json` по сценам, карточка с цифрой первой в сцене, своя съёмка `/opt/shorts/real/clips/own-*`, 3–5 планов на реплику по 1,2–2,2 с. Фактчекер стоит в сборке и не выключается.
- Голос: xAI (`--voice xai`) по рецепту v4. Двойник `/voice/gor` на 5090 — только когда Гор скажет, что версия годна. Читает Гор сам — отдать текст для начитки; до упаковки поправить строку «озвучка синтезирована» в `publish_pack` (память `deleader3-9950x3d-shorts`).
- Упаковка `docs/scripts/pack_project.py`, обложка `shorts-cover`, приёмка `video-critic-loop`, ролик `SendUserFile` Гору, заливка по «да». Для Instagram тот же ролик, подпись — навыками в `Documents\git\instagram`.

## Чек-лист перед выдачей

1. Тема своя, у каждого числа строка в `source.txt`; цифр референса в сценарии нет.
2. Разбор заполнен: хук, структура, монтаж, один приём, «берём / не берём»; метрики только из `meta.json`.
3. Хук того же типа, до 30 знаков голосом, цифра в титре с 0 с.
4. `ref_stats.py --ours` код 0, `check_script.py` код 0.
5. Вердикт в финале одной фразой; нет «подписывайтесь», коммент-слова, цен, «когда покупать».
6. `tg_caption` повторяет сценарий; для ВК без Telegram.
7. Передача в сборщик описана: голос, кадры, папка на хабе.
