# Наш сценарий по референсу: формат, перенос приёмов, приёмка

Подробности к шагам 5–7 `SKILL.md`. Формат и пороги взяты из рабочих роликов «Из мастерской»
(`shortsmaker/docs/scripts/own-*`, `shortsmaker/docs/research/anti-fomo/second-product.md` §1–2) и рецепта v4
(память `shorts-v4-recipe-approved`), язык — `yazyk-vygody`, голос — память `gor-voice-slog-2026-10-06`.

## 1. Перенос: что из референса становится чем у нас

| у референса | у нас | правило |
|---|---|---|
| тип хука (переворот, боль, цифра, спор) | тот же тип | слова свои; голос хука до 30 знаков без цифр и моделей, цифра и модель — в титре с кадра 0 |
| длина хука в словах | ±2 слова | если их хук длиннее 30 знаков — держим наш предел, а не их |
| первое слово на 0,1–0,5 с | голос с 0,1 с | замер калибровки 08.09: у 24 из 25 топовых первое слово до 0,5 с |
| кадр 0 | настоящий предмет мастерской с цифрой в титре | генерация в кадре 0 запрещена; чужой кадр — только цитатой (`chuzhie-futazhi`) |
| порядок блоков | скелет ниже, блоки переставляются под их порядок | развязка там же по времени, где у них «было → стало» |
| темп планов | 1,2–2,2 с на план, 3–5 планов на реплику | их средний план длиннее 2,2 с — не копировать (память `shorts-cut-tempo`) |
| «вывод не говорить, пусть факты работают» | вердикт мастерской одной фразой и только в финале | `yazyk-vygody` §7 |
| два ключевых пункта | одна сквозная мысль, две-три опорные цифры | на 40 с — 3–4 факта с ориентиром, не больше |
| «коммент СЛОВО — пришлю» | нет | автоматики раздачи нет; призыв ставит упаковка (плашка ТГ на YouTube, «напишите в сообщения» во ВК) |
| «подписывайтесь» | нет | `check_script.py` ловит |

## 2. Скелет «Из мастерской» (40–60 с, 8–12 реплик, 650–950 знаков голоса)

1. 0–2 с — тезис-спор голосом, кадр 0 = наш предмет (сборка, стенд, экран BIOS) с цифрой в титре.
2. 2–10 с — с чем приходят: миф, жалоба, совет из интернета («говорят»), слово клиента с согласием.
3. 10–35 с — наш замер или случай: пара чисел до/после или A/B, карточка из тех же чисел, фото того, на чём мерили.
4. 35–50 с — почему так: механика простыми словами.
5. 50–60 с — вердикт утверждением (включать / не включать / не трогать) и куда дальше.

«Вспышка» 10–20 с: тезис → одна пара чисел → вердикт, 3–5 реплик, около 180–320 знаков (ориентир по
x3dburn_f 14,8 с, кодом не проверяется: `check_script.py` на ней покажет брак длины — это ожидаемо).
Середина 25–30 с — самая конкурентная, туда не целимся (калибровка 08.09).

Длительность по знакам голоса: 630 знаков = 39,7 с, 926 = 56,4 с (замер пилотов); 1080 знаков = 62 с — брак
(потолок ленты 59 с).

## 3. Файлы проекта

Папка `shortsmaker/docs/scripts/<slug>/` (в git контура; на хаб — `/opt/shorts/<slug>/`):

- `final.json` — сценарий:
  `{"hook_title": "...", "lines": [{"voice": "...", "title": "...", "hl": "..."}], "tg_caption": "..."}`.
  `voice` — что звучит; `title` — титр 2–5 слов, цифра из той же реплики; `hl` — одно слово-подсветка (цифра или
  вердикт, не название).
- `source.txt` — первичка, каждая строка с меткой: `[RL#576 2026-04-29]`, `[XLSX <таблица> стр.N]`,
  `[ГОР 2026-10-xx чат]`, `[КЛИЕНТ <дата> чат, согласие]`, `[СПРАВКА <файл/URL>]`. Позиция мастерской — отдельным
  абзацем «[ГОР дословно <дата>]». Сайт gspc-lab.pro и ответы ассистента источником не считаются.
- `theme.json` — `{"id": "<slug>", "title": "<тема одной фразой>", "link": "<наш ролик или пост>", "source": "<RL#…>"}`.
- `ref.md` — ссылка на референс, путь к разбору, строка «взято: … / не взято: …».

## 4. Пример на нашем материале (рубрика ЗАМЕР МАСТЕРСКОЙ)

Референс (условный): английский шортс-переворот «Turning this off does nothing», хук 5 слов, кадр 0 — экран
настроек, развязка на 60 % хронометража, призыв «comment GUIDE». Взято: тип хука «переворот совета», хук до 6 слов,
развязка цифрой во второй трети. Не взято: слова, экран настроек чужой игры, коммент-слово.

Первичка `[RL#576 2026-04-29]`: 9800X3D, CS2, 4 теста по 59 с; SMT ON 854 / 335 / 286, OFF 851 / 330 / 284;
«разница меньше 0.4%»; «старая память от Zen 2».

  {"voice": "В среднем 854 кадра с SMT и 851 без. Разница меньше половины процента.", "title": "854 против 851", "hl": "854"},
  {"voice": "Худший процент кадров без SMT тоже не вырос: 330 против 335 с ним.", "title": "Без SMT 330, с ним 335", "hl": "330"},
  {"voice": "Вердикт мастерской: ради кадров SMT не трогаем.", "title": "Ради FPS не трогаем", "hl": "не трогаем"}

объясняет»). Дробь словами («меньше половины процента»): xAI читает «0,4» как «ноль запятая четыре».

## 5. Приёмка

### Жёсткие стопы (брак = переписать, не обсуждается)

| что | чем | код |
|---|---|---|
| число голоса или титра без строки в `source.txt` | `check_script.py` (копия из `own-9850x3d-air`, на хабе питоном HPY) | 2 |
| деньги, «подписывайтесь», эмодзи, `price_rule` | тот же `check_script.py` | 2 |
| реплик не 8–12 или знаков не 650–950 («Из мастерской») | тот же | 2 |
| латиница без русского чтения в словаре | тот же (через `build_short.latin_left`) | 2 |
| цепочка от 5 слов из речи референса | `ref_stats.py <папка> --ours final.json` | 3 |
| факт не подтверждён источником | `fact_gate` в сборке проекта, без выключателя | стоп сборки |

### Оценка (для отчёта, не повод для трёх кругов переписывания)

Перенесена из оригинала (там порог 95/100 и до трёх проходов). У нас мягкие пороги правками не дожимаются
(память `no-rework-for-tiny-thresholds`): балл пишется строкой в отчёт, переписывается только то, что попало
в жёсткие стопы или явно ломает смысл.

| критерий | баллов | что смотреть |
|---|---|---|
| источник | 30 | каждая цифра и каждое утверждение из первички; смысл числа (что мерили, в чём) |
| голос и язык | 25 | «ты» одному зрителю, фраза 6–14 слов, удар до 4 слов примерно в каждой третьей; польза → факт → название; без парных афоризмов подряд |
| хук и структура | 20 | тип хука референса узнаётся, развязка на месте, вердикт только в финале |
| длительность | 15 | знаки голоса в окне, оценка в секундах по замеру пилотов |
| подпись и воронка | 10 | `tg_caption` повторяет сценарий, без цен; для ВК — без Telegram |

Каждый балл с цитатой-доказательством из сценария. Чек-лист частых нарушений:
первое слово «я» или «мы»; голос хука длиннее 30 знаков или с цифрой; три обрубка подряд («Заменили. По гарантии.
Быстро.») — парцелляция, брак; вывод в середине; новое понятие без пары-пояснения; совет «когда покупать».
