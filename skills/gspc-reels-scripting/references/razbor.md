# Разбор референса: шаблон файла разбора

Заполняется по `stats.md` (счёт `ref_stats.py`), листам `sheet_NN.jpg` и `frame0.jpg` (смотреть инструментом Read),
`meta.json`. Пишется по-русски, даже если ролик английский. Чужой текст — только в разделе «Расшифровка», дальше
своими словами. Файл: `Documents\git\work\reels-ref\<slug>\razbor.md`.

```markdown
# Референс: <автор> — <название в двух словах>

- ссылка: <url> · площадка: <YouTube Shorts / ВК Клипы / TikTok / Reels / файл от Гора>
- длительность <N> с · просмотры <N> · дата <ГГГГ-ММ-ДД> (из meta.json; нет поля — «нет данных», не придумывать)
- выброс или нет: «референс» по умолчанию. «Выброс» только с базой: медиана просмотров N последних роликов автора
  = <M>, этот = <K>, кратность <K/M> (выборка, окно, дата съёма)
- слух: rig large-v3 / hub small (из вывода ref_pull.sh)

## Расшифровка
<фразы с таймкодами из stats.md, раздел «Раскладка по фразам»; для английского — перевод строкой ниже>

## Хук (0–3 с)
- первые слова дословно: «…» · слов: <N> · первое слово на <t> с
- кадр 0: <что в кадре: предмет, лицо, экран, текст> · титр в кадре 0: «…» или нет
- тип хука: переворот («X бесполезно, если…») / угроза-боль / цифра-факт / вопрос с ответом / спор с оппонентом /
  демонстрация результата / «вот это поменяло…»
- что держит палец: <одна фраза: пробел любопытства, конфликт, неожиданная цифра, движение в кадре>

## Язык
- средняя фраза <N> слов, самая длинная <N>; темп <N> слова/с
- обращение: ты <N>, вы <N>, я <N>, мы <N> — к кому говорит
- связки между пунктами: <«а вот где подвох», «и тут», «но»…>
- смягчители «просто, всего, лишь»: <N>, где

## Структура
| время | блок | что происходит | приём |
|---|---|---|---|
| 0–3 | хук | | |
| … | | | |
| … | развязка (было → стало) | | |
| … | призыв | <что просит: подписка, коммент-слово, ссылка, ничего> | |

## Монтаж
- планов <N>, средний <N> с (scene 0,3; мягкие склейки сверены по листам: <да/нет>)
- планов на фразу: <обычно N>
- титры: <сколько, где, капс или нет, сколько слов>
- звук: <музыка, эффекты на склейках, голос сверху> (их звук мы не берём никогда)

## Один главный приём
<одна фраза: что именно делает этот ролик сильным и что из этого переносимо в наш формат>

## Что берём / что не берём
- берём: <тип хука, длина хука в словах, порядок блоков, темп планов, место развязки>
- не берём: их слова и фразы, их кадры и звук (цитата кадра — только по `chuzhie-futazhi`), их цифры без нашего
  источника, призыв «напиши слово в комментах»
```
