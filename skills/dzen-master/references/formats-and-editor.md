## 1. Матрица форматов — ОФИЦИАЛЬНО

| Формат | Лимиты | В ленте | Деньги и охват |
|---|---|---|---|
| **Статья** | заголовок ≤140 без ссылок (рекомендовано 15–25); текст ≤100 000 знаков; вложений ≤100; картинка ≥300 px, ≤30 МБ (в приложении ≤10 МБ), подпись ≤2000; галерея ≤30; H2/H3 → оглавление; таблиц нет | карточка: обложка + заголовок + автоописание из первых предложений (до 1000 знаков); своя вкладка «Статьи»; может уйти в ОК | монетизируется; CTR считается |
| **Пост** | ≤4096 знаков; из оформления только ссылки и эмодзи; ≤10 картинок каруселью, первая — обложка, ≤30 МБ; опрос 2–5 вариантов (вопрос ≤150, ответ ≤100, только десктоп, без картинки); «только подписчикам» | целиком в ленте; в общей ленте рекомендаций 3 дня, затем в канале и по ссылке (about/brands) | монетизируется; VTR вместо CTR |
| **Видео** | 5 с – 8 ч; MP4, moov в начале, без edit lists; ≤FullHD, ≤70 ГБ, ≤480 мин, ≤60 fps; H.264 progressive без открытых GOP; AAC стерео 44,1/48/96 кГц; громкость ниже −12 LUFS; заголовок ≤140, описание ≤5000, тегов ≤5; обложка 1920×1080 png/jpg (менять можно после публикации); эпизоды — ≥3 таймкода, первый 00:00, шаг >2 с; пачка 1–20 файлов, каждый — черновик | автоплей **без звука** — вшивать субтитры | не монетизируется с 14.04.2025 |
| **Ролик** | 9:16, 5 с – 2 мин; оптимум 720×1280, максимум 1080×1920; вертикаль >120 с публикуется как «Видео» и в ролики не попадает | подборка вертикальных карточек, полноэкранный свайп; отдельной вкладки в нижней панели приложения нет | не монетизируется; Промо Видео — только горизонтальные |
| **Подборка** | название ≤80, описание ≤300, обложка ≤10 МБ, ≤1000 публикаций, число не ограничено | не формат ленты; в новом дизайне справа видны 3 выбранные | рубрикатор |
| **Трансляция** | своих эфиров нет; запись из VK Видео Live приходит горизонтальным видео (≤70 ГБ, ≤8 ч) | как видео | как видео |

Ещё: закреп до 3 публикаций любых форматов; репост чужой публикации с подводкой (авторство сохраняется); упоминание
`@канал`; QR-код канала (ч/б или цветной); совместный доступ (роли Владелец, Администратор, Редактирование,
Просмотр; доступ сразу ко всему, включая черновики и отложенные; монетизацию видит только владелец).

Отложенная публикация (delayed-publishing.html): посты, статьи, ролики, видео; от 1 часа до 365 дней (ролики из
приложения iOS — от 3 часов); по местному времени автора; проверка до выхода; показ сразу после публикации; статус
«Будет опубликовано в…», вкладка «Отложенные» (в editor.html — «Ожидают публикации»). Лимит числа не указан.

## 2. Редактор статьи — ОФИЦИАЛЬНО (article.html)

- Блоки: абзац, H2/H3 (из них оглавление), маркированный и нумерованный списки, цитата, картинка с подписью,
  галерея, видео Дзена и YouTube ссылкой (виджет), VK Видео — кодом вставки (если страница и видео публичны),
  Яндекс Формы (на десктопе виджет, в приложении ссылка), полужирный, курсив, зачёркнутый, гиперссылка.
- **Таблиц нет.** Таблица замеров — скриншотом настоящей таблицы или графиком кодом, ключевые цифры текстом рядом
  (КЕЙС практики авторов, ГИПОТЕЗА про поиск и дочитывание).
- Окно «Опубликовать»: проверить заголовок, выбрать обложку, «Опубликовать позже», кто комментирует, отметка
  «Партнёрский материал» (метка под заголовком для нативной рекламы, erid не даёт), Scroll-to-site — только при
  привязанном кабинете VK Рекламы. Заголовок раздела комментариев (до 80 знаков) ставится после «Опубликовать»
  (t.me/zenforcreators/1969, 10.12.2025).
- Статусы: Черновик / Ожидает публикации / В обработке (от минут до часов) / Опубликовано / Есть неопубликованные
  правки / Заблокировано.
- Правка опубликованной «не повлияет на «возраст» статьи, её отображение в ленте рекомендаций и уже набранную
  статистику». Пока правки не опубликованы, статьи нет в ленте, она доступна по прямой ссылке; после публикации
  правок лента обновится через несколько минут. Править одним заходом.
- Удаление безвозвратно. Удалённое и выложенное заново — дубликат.

одна законченная мысль — один абзац; подзаголовки информативные, не метафоры; «подзаголовки помогают публикации

каждые 2–3 строки; галерея добавляет время в публикации; больше трёх эмодзи в посте — «дурной тон».

## 4. Телеграм-бот @zen_sync_bot — ОФИЦИАЛЬНО (cross-platform.html)

- Подключение: Студия → Настройки → Кросспостинг → Telegram → «Получить код доступа» (код живёт 30 минут) → код
  боту → `/sync` → бот в админы ТГ-канала (расширенные права не нужны). ТГ-канал публичный, один на канал Дзена.
- Таблица форматов (разобрана скептиками по HTML-иконкам):

| Пост в ТГ | В Дзене |
|---|---|
| только текст | статья |
| текст + картинки | статья |
| текст + видео | статья |
| только картинка | пост |
| только видео | пост |
| опрос | пост |
| кружок, аудиосообщение, рекламный пост с ERID, репост из чужого канала | не публикуется |

- Заголовок — первое предложение (≤140), обложка — первая картинка, форматирование ТГ не переносится, медиа ≤20 МБ.
  «Статьи из бота будут рекомендоваться в соответствии с ограничениями» канала.
- Режимы: автоматический по умолчанию (через несколько минут; правки в ТГ подтягиваются; удаление в ТГ публикацию в
  Дзене не удаляет); ручной — `/changemode`, пересылка поста боту, синхронизация разовая. `/restart` — перепривязка,
  `/help` — команды. Отключить — убрать бота из админов; перенесённое удалять руками.
- UTM: Настройки → Кросспостинг → Телеграм → «Изменить значения UTM-меток в ссылках импортируемых постов»,
  `utm_source=Zen_Posts`.
- Наш замер: видео из ТГ пришло постом (`item_type: brief`) с вложением gif и заголовком `t.me/goldensamplepcs/687`.
  Шортс через бота **не становится «Роликом»**. Ролики — только загрузкой файла в Студии.
- УСТАРЕЛО: «лимит 1500 знаков и без видео/GIF» из пересказов запуска бота.

## 5. Шортсы в Дзен — правила рендера

- Отдельный рендер для Дзена, загрузка файлом: Студия → «Создать публикацию → Загрузить видео»; формат определяется
  по 9:16 и длине ≤2 мин. Обложка — стоп-кадр: кадр 0 с предметом и цифрой (ГИПОТЕЗА). После публикации ролик

- **Без плашки Telegram, t.me-адреса, @-ников и логотипов площадок** в кадре: «водяные знаки других платформ» =
  заимствованный контент (ОФИЦИАЛЬНО). Отнести плашку ТГ к этому — ГИПОТЕЗА с высокой вероятностью. Свой логотип
  GSPC и знак видеоредактора — можно (пост Дзена 02.11.2021). Ссылка на ТГ — в описании ролика.
- `publish_pack.py` кладёт «ролик с плашкой призыва @goldensamplepcs» — для Дзена брать вариант без плашки.
- **Голос**: «автоматически сгенерированная озвучка видео» — спам. Ночная сборка с 30.09 идёт с Grok TTS
  (`SHORTSMAKER_VOICE_ENGINE=xai`), по умолчанию — клон `gor-local`. Оба синтетические (ГИПОТЕЗА о клоне). В Дзен — только
  живая запись голоса или ролик без голоса (титры и звук съёмки).
- Видео файл после публикации не заменить, а удалить и перезалить = дубль: проверять вотермарки и голос **до**
  загрузки (ГИПОТЕЗА по справке).
- Описание ролика ~200 знаков, хэштегов ≤5 — практика postium.ru (КЕЙС, 17.09.2026), лимита в справке нет.
- Гибрид (ГИПОТЕЗА): наш ролик, залитый в Дзен, встроить в статью — он получает зрителей через охват статьи и ОК.

## 6. RSS своего сайта — ОФИЦИАЛЬНО

Действует `website/site-to-channel.html` и `website/rss-modify.html`. Спецификация `export-content/export.html`
(contentType `blogs_only`, картинки ≥480×320, «последние 7 дней») — это экспорт для партнёров «Новостей в Дзене»,
к сайту мастерской не относится.

- Условия: канал ≥10 подписчиков; сайт в свободном доступе, «в основном оригинальный контент» (не дубли с Дзеном, не
  заимствованное, не UGC); без накрутки и «обильной зарекламленности»; IDN-домен нельзя (gspc-lab.pro подходит).
- Путь: Студия → Настройки → «Свой сайт» → домен → HTML-файл или метатег → «Настроить трансляцию материалов сайта в
  Дзен» → лента на проверку. Отказ по технике — повтор сразу после исправления; по содержанию — через 6 месяцев.
  Дзен вправе отклонить без объяснения; отказ на статус канала не влияет. Уведомление — в Студии (КЕЙС prozen.ru/a/5751,
  05.10.2026: раньше было 3 попытки в год — УСТАРЕЛО).
- Первая лента ≥10 материалов, на сайте ≥3 публикаций за последний месяц; в ленте — материалы за 2–3 последних дня;
  уже отправленный материал повторно не добавлять; не больше 500 за раз; guid не менять.
- Обязательные теги item: title, guid, pubDate (RFC822), link (ЧПУ без UTM), content:encoded (полный текст,
  рекомендовано ≥300 знаков). Разметка: p, a, b, i, u, s, h1–h4, blockquote, ul/ol. Таблиц и canonical нет.
  Картинки img или figure шириной ≥700 px, обложка — enclosure.
- category: `native-draft` — ляжет черновиком в Студию (pubDate не действует, публикует человек); без неё —
  опубликуется сразу. `format-article` / `format-post` (пост >4000 знаков и >10 картинок станет статьёй; без
  format: <800 знаков без картинок или <600 знаков и ≤10 картинок — пост). `index` / `noindex`. `comment-all` /
  `comment-subscribers` / `comment-none`.
- Правки через RSS принимаются 7 дней после первой загрузки и только пока статью не правили руками.
- RSS-статья — материал, опубликованный на платформе, раздаётся в ленте наравне с ручными (website-owners.html,
  statistics/rss.html).

Наш путь (ГИПОТЕЗА): `native-draft` = «конвейер кладёт, человек публикует», совместимо с гейтами. Одна статья — один
путь: руками или RSS. Кросс-доменного canonical Яндекс не учитывает (справка Вебмастера), в Дзене его нет. Выбор:
сайт первым и `noindex` у копии в Дзене, если важен поиск на сайт, или отдельная переработанная версия для Дзена.

  адреса на другой редирект работает только 14 дней; для перехода с адреса `/id/…` такого предела справка не
  называет. Дзен может отозвать короткий адрес без объяснений.
- Верификация (verification.html, ОФИЦИАЛЬНО): галочка при одном из критериев — СМИ-партнёр Новостей,

  даёт» — публикации показываются наравне.
- Подтверждение контактов: при входе через Яндекс ID перед первой публикацией подтвердить почту и телефон —
  Настройки → Контакты, только десктоп (confirm.html).
- Мобильная Студия: статьи, посты, видео, ролики, черновики синхронизируются; вывод денег и расширенная статистика —
