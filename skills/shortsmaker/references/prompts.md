## ⛔ ГРАБЛЯ №1, оплачена: грязь и износ в предметке запрещены

Стиль с «visible dust, fine scratches, real solder joints, slightly bent» дал кадры,
которые Гор назвал «фото брака» — оплавленные детали в грязи и припое. Механика по
замеру imagine-prompting (2.5): **состояние ложится поверх материала и заражает всё
окружение**. Заказал пыль на одной детали — получил помойку во всём кадре.

Для канала, продающего премиум-железо, деталь в кадре **всегда новая, с завода,
безупречно чистая**. Запрещённые слова в любом промпте предметки: пыль, царапины,
припой, изношенный, погнутый, старый, потёртый, залапанный (последнее рисует
буквальные папиллярные узоры — замер 2/2).

Достоверность даёт не грязь, а свет схемой и честная оптика.

## Чего у Grok Imagine нет

`seed` и `negative_prompt` API **принимает и молча игнорирует** (два прогона
seed=777 — разные файлы). Воспроизводимости нет в принципе — отсюда закон сида.

## Закон сида (из imagine-prompting, подтверждён)

Два кадра одного промпта расходятся сильнее, чем кадры разных промптов. Поэтому:
- вывод по одному кадру = шум; правку промпта принимать двумя прогонами
- **всегда `n:4` и отбор**; в конвейере отбор делает vision-судья (ниже)
- холст стохастичен вплоть до поворота — размер файла проверять до отбора

## Параметры, проверенные живьём (закрывают P0 скила imagine-prompting)

| параметр | значение | результат |
|---|---|---|
| `aspect_ratio` | `"9:16"` | работает напрямую в api.x.ai (их 422 был словарём прокси) |
| `resolution` | `"1k"` / `"2k"` | 720×1280 / **1584×2816**; 2k +$0.02 |
| `n` | до 10 | 4 дубля 2k за $0.28 одним вызовом |
| `/v1/images/edits` | HTTP 200 | исходник читается — якорь стиля возможен, глубоко не зондирован |

Цены: `image` $0.02, `quality` $0.05 (1k) / $0.07 (2k), `2.0` $0.06–0.08.

## Каркас промпта (по imagine-prompting, работает и в предметке)

Блоки капсом, по-русски — весь их корпус замеров русскоязычный:

```
СУБЪЕКТ: крупный план <конкретная деталь>, новая и чистая.
МАТЕРИАЛ И СОСТОЯНИЕ: деталь новая, только с завода, безупречно чистая: ни пыли,
ни царапин, ни отпечатков; чёрный матовый пластик, шлифованный алюминий.
СВЕТ: строго один источник: большой софтбокс слева сверху под сорок пять градусов,
мягкий, с плавной границей тени, нейтральный белый 5600K; справа белая отражающая
карта; на металле длинный ровный блик.
ПАЛИТРА строго из четырёх цветов: графитово-чёрный, серебристый алюминий,
тёмно-серый фон, холодный белый блик. Других цветов в кадре нет.
КАДР: макро, предмет занимает большую часть кадра, фон размыт до мягкой мути,
вертикальный кадр девять к шестнадцати. Это фотография продукта.
Никаких надписей, никаких логотипов, никаких людей.
```

Несущее из их замеров:
- **свет схемой — единственный воспроизводимый рычаг** (7/7): источник-предмет,
  сторона, угол словом, жёсткость, цвет словом + Кельвины, «заполняющего света нет»
- палитра: 3–4 названных цвета + замок «Других цветов в кадре нет»
- порядок блоков — нерабочий рычаг, не тратить итерации
- отрицать можно слой или режим («никаких надписей»), нельзя часть объекта
- материал называть только когда спорит с дефолтом предмета
- крупность — описанием видимого и срезанного, не термином

## Отбор дублей: vision-судья (ярус 4 QC)

`grok-4.20-0309-non-reasoning` видит картинки через тот же OAuth (замерено 08-14),
0,6–3 с на вызов. В `build_short.py` это `vision_pick()`: каждый дубль → вопрос
«ДА или НЕТ: грязь, потёки припоя, деформированные элементы, невозможная
геометрия?» → берётся первый чистый. На живом прогоне забраковал 2 дубля из 16 —
ровно те, где радиаторные рёбра поплыли.

**Отбор по максимальному размеру файла запрещён**: он выбирает самый замусоренный кадр.

## Текст в кадре

Кириллица у линии живая (их замер: 174 знака без ошибки), но **цифры, знаки
препинания и строчные не мерены** — а у нас в кадре в основном цифры и «€».
Поэтому все надписи по-прежнему кладёт ffmpeg `drawtext` поверх. Если когда-то
заказывать текст генератору — только заглавную кириллицу 3–5 слов, формулой из
imagine-prompting §2.7, и n:4.

## Модели

| задача | модель |
|---|---|
| предметка канала, базовый путь | **`grok-imagine-image-2.0`**, 2k, n:4 — светотень и материалы заметно дороже (дуэль 08-14 на радиаторе, совпало с их абляцией) |
| кадр, где мелкая деталь ТЗ обязана удержаться | `grok-imagine-image-quality` (их замер A20) |
| дешёвый массовый фон | `grok-imagine-image` $0.02 (не мерена ни одной осью) |

Переключение: `SHORTSMAKER_IMAGE_MODEL`. Геометрии врут обе (2.0 ломала рёбра
посреди панели на 1 дубле из 4) — vision-гейт обязателен любой модели.

## Неевклидова геометрия (регистр для арт-кадров, не для продуктовых)

Модель понимает буквально: `non-Euclidean impossible geometry`, `Escher`, `Penrose`,
`two conflicting vanishing points` + обязательное «rendered matter-of-factly and
photorealistically», иначе уходит в иллюстрацию.

Что ломает эффект (оплачено пробами):
- **плотная фактура выпрямляет перспективу** — когда стены пустые, врать нечем, кроме
  геометрии; забитый компонентами кадр съедает невозможность. Ломать компоновку
  (пол переходит в потолок без стыка), а не перспективу
- **непрерывная RGB-полоса чинит геометрию** — свет объясняет форму; полосы должны
  обрываться не там, где ждёшь
- геометрия ставится **первым блоком** промпта

## Абстрактная тема

Один герой-кадр на эпизод, движение камеры меняется, смысл несёт drawtext-слой.
Не генерировать новый кадр на каждую фразу.

## Референс обязателен для конкретной детали (правило Гора 08-20)

Когда сцена показывает **узнаваемый компонент** (конкретный сокет, разъём, форма
крышки процессора, раскладка платы), НЕ генерировать по памяти — сначала посмотреть
реальные фото. Это не запрещено, это нормальная работа режиссёра.

Оплачено 08-20 на 9950X3D: по памяти я генерил гладкую серебряную крышку в квадратном
сокете. Реальность:
- **IHS Ryzen 9000** — не гладкий прямоугольник, а «крест» с восемью прямоугольными
  лепестками по периметру; между лепестками виден **бирюзово-синий** текстолит с
  золотыми площадками; один угол скошен (метка позиционирования).
- **Сокет AM5** — металлическая рамка Force Frame с прямоугольным окном, внутри
  плотное **золотое поле пинов LGA**, разделённое перемычкой пополам; сбоку
  рычаг-защёлка; по углам чёрные винты. НЕ пустая серебряная площадка.

Как смотреть с VPS (без правки прод-кода): `grab_ref.py` в scratchpad — headless
через `/opt/hermes/venv`, тянет крупные фото из Bing Images по запросу, сохраняет
в `/tmp/ref_*`. Смотреть глазами (Read по превью), затем описывать в промпте то,
что РЕАЛЬНО на фото. tpucdn.com (TechPowerUp) отдаёт оригиналы напрямую.

Проверка результата — та же: сгенерированный кадр сверить с референсом на совпадение
ключевых признаков (у сокета: перемычка поля пинов, рамка, рычаг; у крышки: лепестки,
цвет текстолита), и только годное — в костяк.
