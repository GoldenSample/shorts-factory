FreeVideo (MiniMax H3, 28,6 ГБ, `C:/Apps/freevideo`, замер 06.10) стоит, но в роликах не применялся: статус «лежит» в реестре, генератив в пределах 20 %. - procedural-film по своему README гонит отдельного агента Claude на каждый план плюс критиков: это жжёт лимит подписки. Без прямого слова Гора брать law-скил и править его готовый пример ОДНИМ агентом, без веера.
