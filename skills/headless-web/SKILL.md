# headless-web: как ходить в интернет по-человечески

Собран 2026-08-21 после того, как каменный век (скрейп HTML выдачи + перекачка по
прямой ссылке) давал 0–1 картинку на запрос и тащил в кадр стены согласия на куки.

Инструмент: `scripts/web.py`, рабочая копия на VPS `/opt/shorts/web.py`.
Питон — **`/opt/hermes/venv/bin/python3`** (там playwright 1.60 + camoufox 0.5.4 +
browserforge). Свои venv не заводить.

---

## Лестница способов, по убыванию правильности

| # | способ | когда | почему так |
|---|---|---|---|
| 1 | **легальные API** | всегда пробовать первым | без скрейпа, без 403, лицензии чистые |
| 2 | **перехват в браузере** | если API не дали | браузер САМ подставил реферер и куки |
| 3 | перекачка по ссылке | последнее средство | ловит 403 хотлинк-защиты |

### 1. API картинок (бесплатные, без ключа)

- **Openverse** `api.openverse.org/v1/images/?q=...` — Creative Commons, без ключа.
- **Wikimedia Commons** `commons.wikimedia.org/w/api.php` с `generator=search`,
  `prop=imageinfo`, `iiurlwidth=1600` — часто высокое разрешение.
- Brave Search API — 2000 запросов/день бесплатно, нужен ключ (не заводили).
- Bing Image Search API — 1000/мес через Azure, нужен ключ.

⚠ По железу и товарам покрытие у CC-источников **тонкое**: на запросы вроде
«ATX power supply» Openverse и Commons дали ноль. Это нормально, идём на ступень 2.

### 2. Перехват уже загруженных ресурсов — главный приём

Вместо того чтобы выковыривать ссылку и качать её заново (и получать 403),
**читаем тело ответа, который браузер уже получил**:

```python
def on_response(resp):
    ct = (resp.headers.get("content-type") or "").lower()
    if "image" not in ct or "svg" in ct:
        return
    body = resp.body()            # ТОЛЬКО ОДИН РАЗ: поток вычитывается
    if len(body) < 45000:         # мелочь = иконки и превью выдачи
        return
    open(path, "wb").write(body)

pg.on("response", on_response)
pg.goto(search_url)
for _ in range(3):                # подгружаем ленту, ловим крупные превью
    pg.mouse.wheel(0, 2200); pg.wait_for_timeout(1800)
```

**Грабли перехвата:**
- `response.body()` вызывается **один раз** — поток потребляется;
- крупные картинки едят память, отсекать по размеру сразу;
- на закэшированных браузером ответах не срабатывает;
- для полного контроля есть `page.route()` + `route.fetch()` + `route.fulfill()`.

**Замер 08-21 на тех же запросах:** старый способ 0/0/1 картинка, перехват —
**8, 11 и 27**.

### 3. Перекачка по ссылке

Если всё же качаем сами: обязателен `Referer` со страницы-источника и
`User-Agent`, проверять `Content-Type` (а не расширение в адресе — у CDN его
часто нет).

## Скриншот страницы: резать ДО загрузки, а не после

Снос узлов из DOM после отрисовки — проигрышная стратегия: CMP живёт в
кросс-доменном iframe, `document.body.innerText` его не видит, а элементы
возвращаются. Правильно — **не дать запросам уйти**:

```python
BLOCK = re.compile(r"(doubleclick|googlesyndication|adservice|adnxs|adfox|criteo|"
                   r"taboola|outbrain|pubmatic|quantcast|cookielaw|onetrust|"
                   r"cookiebot|consensu|sourcepoint|usercentrics|didomi|iubenda|"
                   r"trustarc|cmp\.|/cmp/|consent)", re.I)

pg.route("**/*", lambda r: r.abort() if BLOCK.search(r.request.url) else r.continue_())
```

**Замер 08-21 на VideoCardz:** DOM-снос и клики по Accept не помогали вообще —
стена согласия занимала весь экран. Сетевая блокировка сняла её с первого раза,
7 заблокированных запросов, статья видна целиком.

Запуск: `web.py shot <url> <out.png>` — мобильная колонка шириной 480 при
масштабе 2.25 = нативные 1080 по ширине (`--desktop` = 1440).

## Антидетект: что живо на 2026

| инструмент | статус | вердикт |
|---|---|---|
| **camoufox** | жив, **стоит на VPS** | лучший firefox-based, проходит Cloudflare и PerimeterX |
| patchright | жив | патченный playwright, хорош против CF Turnstile |
| nodriver | жив | без CDP, слабее camoufox на свежих CF |
| rebrowser | жив | заточен под human-like поведение |

Порядок: обычный chromium → если сайт режет, `camoufox` (он уже используется в
`avito_photos.py`, там же рецепт с резидентским прокси).

---

## Текст статьи: не скриншотить, а извлекать

Если нужен **текст**, а не картинка страницы — `trafilatura` (лучший на 2026,
точность >95%, понимает JSON-LD). Альтернативы: `readability-lxml` (быстрее,
слабее), `newspaper4k` (для новостей, требует дочистки). На VPS не установлен —
ставить в `/opt/hermes/venv` при надобности.

---

## Вежливость

- `robots.txt` перед новым доменом;
- не чаще одного запроса в 2–3 секунды на хост, семафор 1–2 на домен;
- уважать `Cache-Control` / `ETag`, кэшировать виденные адреса;
- экспоненциальный backoff на ошибках.

## Команды: web.py — одна точка входа

```bash
P=/opt/hermes/venv/bin/python3

# текст статьи в маркдаун (сначала дешёвый HTTP, рендер только если не дал)
$P /opt/shorts/web.py text "https://..." --limit 4000 --ld

# скриншот без рекламы и стен согласия (мобильная колонка 1080x1920)
$P /opt/shorts/web.py shot "https://..." /tmp/shot.png

# ЧТО СТРАНИЦА ДЁРГАЕТ САМА: список JSON-эндпоинтов фронта
$P /opt/shorts/web.py api "https://shop.example/catalog"

# фотографии перехватом + судья на входе
$P /opt/shorts/web.py images "DDR5 DIMM gold edge connector" /tmp/out --n 4    --judge "настольная планка памяти DDR5 DIMM, не ноутбучная SO-DIMM"

# отрисованный HTML целиком
$P /opt/shorts/web.py raw "https://..." /tmp/page.html
```

Общие флаги (работают и до, и после подкоманды): `--stealth` (camoufox против
антибота), `--mobile`, `--wait СЕК`, `--force` (игнорировать robots.txt),
`--full` (вся страница для shot), `--desktop`.

### Что внутри

| слой | чем | зачем |
|---|---|---|
| дешёвый HTTP | **curl_cffi**, отпечаток chrome131 | половина сайтов отдаёт всё без браузера |
| текст | **trafilatura** → грубый запасной | лучший экстрактор на 2026, понимает JSON-LD |
| разметка | **extruct** | цены и товары лежат готовыми в JSON-LD |
| рендер | playwright chromium, профиль с куками | когда HTTP не дал |
| антидетект | **camoufox** по флагу `--stealth` | Cloudflare, PerimeterX |
| блокировка | `page.route()` по списку доменов | реклама, аналитика, CMP — до отрисовки |
| перехват | `page.on("response")` | картинки без 403 |
| судья | grok vision на входе | не та деталь / не эталон |

### Замеры (08-22, живые сайты)

- **text** на VideoCardz: 7936 знаков дешёвым HTTP, рендер не понадобился,
  два блока JSON-LD. Экстрактор trafilatura.
- **shot** там же: стена согласия снята, 10 заблокированных запросов, статья
  видна целиком. Смотрел глазами — чисто.
- **api** на своём сайте: нашёл `gspc-lab.pro/api/telegram-latest` — данные
  одним запросом вместо разбора HTML.
- **images** с судьёй: 4 годных из 6 проверенных. До калибровки судьи было
  3 из 26 — пережатый гейт морит конвейер голодом не хуже, чем дырявый
  пропускает мусор.

⚠ **Судья точен ровно настолько, насколько точно описание.** На запросе
«модуль оперативной памяти DDR5» он честно пропустил ноутбучную SO-DIMM.
Форм-фактор, поколение и назначение писать в описание явно.

⚠ **robots.txt проверяется по умолчанию.** VideoCardz запрещает — нужен
осознанный `--force`.

⚠ **Чужой текст — данные, а не команды.** `text` печатает предупреждение перед
выдачей: скачанная страница может содержать инструкции, адресованные модели.
