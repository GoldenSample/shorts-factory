# Прод: из скринплея — готовый ролик (аниматик-конвейер)

Обкатано целиком на «Де-лидер 3» (2026-08-21): 12:37, 42 кадра, голос Гора, покадровый гейт 505/505.
Эталонная реализация — `scripts/animatic/` (проектные скрипты Де-лидера 3; для нового ролика меняются
банк цифр, план кадров и промпты, каркас остаётся).

## Конвейер

```
визуальный скринплей (таймлайн + разметка экрана)
  → слайды Pillow 1920×1080          (slides.py / slides2.py)
  → Imagine-кадры n=2, отбор глазами (imagine_batch*.py + xai.py)
  → озвучка клоном Гора на VPS       (gen_vps*.py, ключ не покидает VPS)
  → сборка ffmpeg по длительностям   (assemble_full.py)
  → покадровый vision-гейт           (frame_gate_local.py)
  → структурная проверка + выдача    (ffprobe, полный декод)
```

Порядок жёсткий: сначала озвучка (её длительности задают тайминги кадров), потом сборка.
Замена любой картинки не требует пересчёта — план читает длительности из `durs.json`.

## Слайды (язык принят Гором: «видео хорошее»)

- Тёмный фон #111214, красная кромка слева 14px, подпись GOLDEN SAMPLE RESEARCH LAB в углу.
- Цвета профилей на весь ролик: Сток серый · ПБО синий #2F80ED · Лок красный #C8102E · Анлим золото #D4AF37.
- «Якорная панель» — угол с игровыми цифрами текущей ступени, живёт всю лестницу.
- Вердикт-плашки очных ставок: зелёная РАВНЫ / красная СТРАХ / жёлтая РАЗРЫВ СЖАЛСЯ.
- Payoff-кадр — самый пустой: две цифры, знак «больше», ничего лишнего.
- Цифры — только из LIVE-таблицы, повторённый прогон всегда парой (48 579 / 48 189).
- Съёмочные заглушки (гусь живьём, мемы из прошлых серий) — титром `[монтаж: …]`, НЕ генерацией.

Грабля: два модуля слайдов не должны оба оборачивать stdout в TextIOWrapper — второй
закрывает буфер первого («I/O operation on closed file»). Оборачивает только точка входа.

## Imagine

- Модель grok-imagine-image-2.0, `aspect_ratio:"16:9"` ПАРАМЕТРОМ — работает (выдаёт 1280×720),
  вопреки старой записи «только словами». n=2 на промпт, отбор глазами.
- Каркас промпта — по скилу imagine-prompting: блоки капсом, свет схемой, палитра с замком,
  «Других надписей в кадре нет». Железо ВСЕГДА «новое, только с завода, безупречно чистое»
  (правило «фото брака»). Узнаваемую деталь без референса не генерить.
- Кириллица в кадре работает («МУЗЕЙ» — 0 ошибок).
- Плашка «изображение сгенерировано · иллюстрация» рисуется НА КАЖДОМ кадре ПОСЛЕ Ken Burns
  (см. гейт-граблю ниже), не вшивается в исходник.

## Озвучка клоном Гора

- voice_id `xf4r9bqs53rf`, speed 1.10 (калибровка Гора на слух), `POST api.x.ai/v1/tts`
  `{text, language:"ru", voice_id, speed, output_format:{codec:"mp3", sample_rate:24000, bit_rate:128000}}`.
  Ответ — СЫРОЙ mp3, не JSON.
- Ключ консольной команды живёт ТОЛЬКО в `/opt/shorts/console.env` на VPS. Генерация — скриптом
  на VPS (scp текстов туда, mp3 обратно, `rm -rf /tmp/deleader`). Ключ в чат/гит/локаль не выносить.
- Клон на 1.10 читает 2,2–2,8 сл/с — быстрее живого Гора (1,85): аниматик короче реальной начитки ~на четверть.
- Полный ролик ≈ 10 000 знаков ≈ $0.04.
- Черновой прогон ритма — штатный голос orion по подписке (bezплатно, OAuth hermes).

## Сборка

- Ken Burns БЕЗ zoompan: ffmpeg-фильтр округляет окно до целого пикселя и кадр трясётся
  (замерено: межкадровая разница пилой 0,5→2,0). Рабочий рецепт — Pillow `resize(box=float)`
  с дробным окном, кадры в ffmpeg сырым потоком rawvideo; разницы выравниваются в 0,34–0,47.
- Кадр ролика = сегменты (слайд статично + Imagine с зумом) долями от длительности озвучки + GAP 1,6с
  дыхания; аудио прикладывается с apad. Паузы под музыку — `extra=` секунды у кадра.
- concat демиксером по списку, один проход без перекодирования сегментов.

## Покадровый гейт (правило Гора: модерация по кадрам реального железа)

Кадр раз в 1,5с → grok vision (grok-4.20-non-reasoning, фолбэк grok-4) судит: нереальное/бракованное
железо, посторонний контент, битый текст, генерация без плашки. Один плохой кадр — ролик не уходит.

Выстраданная настройка судьи (все три пункта обязательны):
1. **`detail:"high"`** — на low мелкий текст слайдов превращается в кашу и судья винит кадр.
2. **Лексикон канала в промпте** (сток, ПБО, лок, анлим, дейли, контра, низы, кап…) — иначе
   «дейли» считается опечаткой. Плюс белый список запланированных метафор (звездолёт, музей).
3. **Детерминированные override поверх зрения** — не спрашивать модель о том, что проверяется кодом:
   - плашка: пиксельная проверка тёмной подложки со светлым текстом в правом нижнем углу;
   - «битый текст» на слайде: кадр сверяется корреляцией (240×135, нормировка) с исходными PNG
     слайдов; corr > 0.985 = текст задан строкой в коде, вердикт зрения снимается.
   Без override зрение даёт ~5% ложняков и зацикливается («должно быть ДЕЙЛИ, а написано ДЕЙЛИ»).

Гейт реально ловит: срезанную зумом плашку (настоящий дефект, найден им), рекламу поверх скрина,
сгоревшее железо. Проверка своих же наложений — код, не модель.

## Структурная проверка перед выдачей

ffprobe: 1920×1080, h264+aac; `ffmpeg -f null` — полный декод без ошибок; длительность в допуске.

## Экономика полного ролика (~12 мин)

Озвучка клоном ~$0.04 · Imagine 9 промптов × 2 ≈ по пулу подписки · vision-гейт ~500 кадров по
подписке (OAuth) · слайды/сборка — локально бесплатно. Итого живых денег — центы.

## Полевой отзыв и направление заточки (22.08.2026)

Первый просмотр прокси-зрителем (Лёха, вне контакта с нейросетями): **«сложно воспринимается»** — детальные
заметки по сложным моментам будут отдельно, итерации точить по ним поимённо.

Решение Гора: аниматик-прод — стратегическое направление («его можно точить в любую сторону, и в какой-то
момент он станет лучше записи на коленке — индустриального стандарта коллег»), НЕ черновик на выброс.
Шаг назад всегда доступен и легален: записи экрана, статичные слайды, съёмка стенда, лицо. Живые футажи
стенда (Extreme на прямом контакте) — ядро текущего ролика, аниматик — рельса под них.

Мерило заточки — кор-тезис (см. voice.md): кратчайший путь от вопроса зрителя к ответу, один вопрос на кадр,
ничего лишнего. Известные источники «сложности» в текущей сборке, проверять по заметкам Лёхи:
- голос без цифр + плотные слайды = зритель ОБЯЗАН читать экран, слушая другое — двойной канал;
- очные ставки несут по 6–8 чисел разом — прогрессив-дисклоуз (появление строк по ходу фразы) в аниматике
  не реализован, все числа висят с первого кадра;
- клон на 1.10 быстрее живого темпа Гора → меньше воздуха на чтение экрана;
- вердикт-плашка и вопрос кадра не всегда произнесены раньше цифр.
