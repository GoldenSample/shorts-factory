# Формат проекта CapCut Desktop (draft_content.json)

## Где лежат проекты

- Windows: `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft\<имя проекта>\`
- macOS: `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/<имя проекта>/`

Главный файл проекта — `draft_content.json` (в некоторых версиях рядом есть
`draft_info.json` с похожей структурой). Всё содержимое проекта, включая субтитры, — в нём.

## Правила безопасности (обязательно)

1. **CapCut должен быть закрыт.** Приложение держит проект в памяти и при сохранении
   перезапишет твои правки, а конфликт версий может испортить проект.
2. **Сначала бэкап:** скопируй `draft_content.json` в `draft_content.backup-<дата>.json`
   в той же папке. Скажи пользователю, что бэкап есть и как откатиться (переименовать обратно).
3. **Структура меняется от версии к версии.** Этот документ — карта, а не истина: перед
   правкой посмотри реальный JSON и подстрой пути под то, что видишь. Если структура
   сильно отличается — безопаснее сгенерировать SRT для импорта, чем править JSON вслепую.
4. Меняй **только** текстовые поля субтитров. Не трогай id, порядок элементов и незнакомые
   поля. JSON сохраняй в UTF-8 без BOM, с той же общей структурой.

## Где субтитры в JSON

- `materials.texts[]` — массив текстовых материалов. У автосубтитров обычно
  `type: "subtitle"` (у обычных надписей — `"text"`). Ключевые поля:
  - `id` — идентификатор, на него ссылаются сегменты дорожки;
  - `content` — **строка, внутри которой JSON**: `{"styles":[...],"text":"..."}`.
    Сам текст блока — в поле `text` этой вложенной структуры;
  - `words` — бывает у автосубтитров: пословный тайминг (`text[]`, `start_time[]`, `end_time[]`).
- `tracks[]` — дорожки. Ищи `type: "text"`; её `segments[]` содержат:
  - `material_id` — ссылка на элемент из `materials.texts`;
  - `target_timerange` — `{ "start": ..., "duration": ... }` **в микросекундах**
    (1 секунда = 1 000 000).

Соответствие «блок субтитров = материал + сегмент». Порядок блоков определяется
`target_timerange.start` сегментов, а не порядком в массиве.

## Как править текст блока

`content` — это JSON-в-строке, править аккуратно:

1. Распарси строку `content` как JSON.
2. Замени поле `text` на исправленный вариант.
3. В `styles[]` у каждого стиля есть `range: [начало, конец]` — диапазон символов,
   к которому применён стиль. **Обнови диапазоны под новую длину текста** (в простом
   случае один стиль на весь текст: `range: [0, длина_нового_текста]`).
4. Сериализуй обратно в строку и положи в `content`.
5. Если у материала есть `words` с пословным таймингом и ты изменил состав слов —
   пословный тайминг больше не соответствует тексту. Самый надёжный вариант — удалить
   несоответствие не пытаясь: проверь на копии; если после правки CapCut показывает
   блок некорректно, генерируй SRT и импортируй вместо прямой правки.

## Известный баг: «текст есть, а на видео части слов нет»

Если в субтитрах текст полный, но на видео часть слов не отображается — почти всегда
`range` в `styles[]` покрывает не всю длину строки (например, текст 32 символа,
а `range: [0, 18]`). Лечится расширением диапазона до полной длины текста.
Это стоит проверить и починить во всех блоках, даже если пользователь не жаловался.

## Разбивка блоков при прямой правке JSON

Разбить блок в draft_content.json — значит создать новый материал в `materials.texts`
(с новым уникальным id в том же формате, что существующие) и новый сегмент в той же
дорожке (копия исходного сегмента с новым id, новым `material_id` и пересчитанным
`target_timerange`). Это заметно рискованнее правки текста: у сегментов много
взаимосвязанных полей (`render_index`, `extra_material_refs` и т.п.).

Поэтому по умолчанию для разбивки используй путь через SRT: собери исправленные
и разбитые субтитры в SRT-файл (тайминги из `target_timerange`, перевод из микросекунд),
отдай пользователю на импорт, а прямо в JSON правь только когда структура блоков
не меняется (тот же состав блоков, только текст).

## Конвертация таймингов

- микросекунды → SRT: `00:00:12,345` = 12 345 000 мкс.
- SRT-формат метки: `ЧЧ:ММ:СС,ммм` (запятая перед миллисекундами, не точка).
