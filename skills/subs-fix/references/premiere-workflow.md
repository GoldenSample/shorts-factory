# Adobe Premiere Pro: экспорт и импорт субтитров

Проверено под Premiere Pro 2025 (25.0); в соседних версиях названия пунктов могут
чуть отличаться. Названия даны в формате «русская локализация (English)».

## Почему только через SRT

`.prproj` — это gzip-сжатый XML с недокументированной структурой; текст субтитров
в нём не хранится открытым текстом, и ручная правка файла может сделать проект
неоткрываемым. Поэтому файл проекта не редактируем никогда — путь один:
экспорт SRT → правка → импорт новой дорожкой.

## Если субтитров в проекте ещё нет

1. Окно (Window) → Текст (Text) → вкладка «Расшифровка» (Transcript).
2. «Расшифровать эпизод» (Transcribe sequence) — выбрать язык и аудиодорожку с речью.
3. После расшифровки — кнопка «Создать субтитры» (Create captions, значок CC).
   В диалоге настроек рекомендуй пользователю:
   - максимальная длина: ~25–28 символов для вертикального видео, ~40–42 для 16:9;
   - строк: одна или две;
   - минимальная длительность: ~1 с.
   Premiere режет тупо по символам, не по фразам — финальную разбивку всё равно
   сделает скил, но с адекватными настройками меньше мусора на входе.

## Экспорт SRT из Premiere

Вариант через панель «Текст»: вкладка «Субтитры» (Captions) → меню «···» в правом
верхнем углу панели → «Экспорт» → «Экспортировать файл SRT» (Export to SRT file).

Вариант через меню: выделить дорожку субтитров → Файл (File) → Экспорт (Export) →
«Подписи/Субтитры» (Captions) → формат SRT.

Экспортированный файл обычно в UTF-8; если видишь кракозябры — попробуй cp1251
и пересохрани в UTF-8.

## Импорт исправленного SRT обратно

1. Файл (File) → Импорт (Import), либо Ctrl+I → выбрать `<имя>_fixed.srt`.
   Файл появится в панели «Проект» (Project).
2. Перетащить его на таймлайн — Premiere создаст новую дорожку субтитров.
   **Ставить строго в начало эпизода (00:00:00:00)**, иначе все тайминги уедут.
3. Стиль: выделить блоки новой дорожки и назначить «Стиль дорожки» (Track Style) —
   сохранённый стиль пользователя или настроить в панели «Основные графические
   элементы» (Essential Graphics). Стили со старой дорожки автоматически не переносятся.
4. Старую дорожку субтитров отключить (иконка CC/глаз на дорожке) или удалить
   (правый клик по заголовку дорожки → удалить дорожку).

## Автоматизация

Если в сессии доступны инструменты управления компьютером (computer-use) и Premiere
открыт — предложи пользователю выполнить экспорт/импорт за него по шагам выше.
По умолчанию просто дай шаги: они занимают меньше минуты.

## Известные грабли

- SRT с точкой вместо запятой в миллисекундах (`00:00:01.500`) Premiere может не принять —
  валидатор скила это ловит, стандарт: `00:00:01,500`.
- Пустые блоки (без текста) при импорте иногда смещают нумерацию — валидатор ловит.
- Если в эпизоде fps дробный (29.97), не пытайся «подгонять» тайминги под кадры —
  SRT работает по времени, Premiere сам привяжет к кадрам.
